# Tour Manager - Cross-Platform React Native (Expo) App

A production-ready, 100% offline cross-platform React Native (Expo for Web, Mobile & Desktop) Tour Management and Expense Ledger application designed for trip organizers and members.

Features auto settlement ledger calculation, equal expense splitting, day-wise itinerary planning, packing checklist, emergency contacts, target budget control with dual-color split progress bar, and text/PDF report export.

---

## 🚀 How to Run

### Run Locally on Web (Browser)
```bash
npm run web
# OR
npx expo start --web
```

### Export Web Production Bundle
```bash
npm run build:web
```

### Run on Android / iOS (Future Mobile App)
```bash
# Android:
npm run android

# iOS:
npm run ios
```

---

## 🛠️ Tech Stack
- **Framework**: React Native (Expo SDK 51+)
- **Cross-Platform Engine**: React Native Web (`react-native-web`)
- **State & Storage**: React Context + `@react-native-async-storage/async-storage`
- **Type Safety**: TypeScript
